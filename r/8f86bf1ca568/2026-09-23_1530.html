📖 Recapitulação da Regra
Pronúncia e uso dos demonstrativos (This, That, These, Those)
Usamos 'this' e 'that' para o singular, e 'these' e 'those' para o plural. No plural, a pronúncia final tem o som de Z (/z/), o que ajuda a diferenciar de 'this'.
This is a steel sample for the client.
Esta é uma amostra de aço para o cliente.
Those heavy beams are for the new project.
Aquelas vigas pesadas são para o novo projeto.
