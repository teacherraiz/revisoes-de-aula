📖 Recapitulação da Regra

Preposições de Tempo e Prazos (for, since, during, until, by)

Para indicar o prazo limite de uma entrega (deadline), usamos 'by'. Para ações que continuam até determinado momento, usamos 'until'. Já 'during' indica a duração dentro de um evento ou período.

We must submit the cybersecurity report by Friday.
Precisamos enviar o relatório de cibersegurança até sexta-feira.
The system will be offline during the maintenance window.
O sistema ficará indisponível durante a janela de manutenção.
I have worked on this project for two weeks.
Eu trabalho neste projeto há duas semanas.

🔁 Revisão Cumulativa

Preposições de Tempo e Prazos (for, since, during, until, by)

Usamos 'by' para prazo limite (deadline), 'until' para ações contínuas até um momento, 'during' para períodos e 'for/since' para duração e início.

1. Please send the report ____ Friday afternoon.
2. We stayed in London ____ (for / since) two weeks.
